# Оно тебе надо — аукцион вещей, в которые никто не верил

Проектная работа по вёрстке. Одностраничный сайт-аукцион, выполненный по макету из Figma.

## Ссылка на репозиторий
https://github.com/ваш-аккаунт/ono-tebe-nado-ad

## Технологии
* HTML5 (семантическая разметка)
* CSS3 (Flexbox, CSS Grid, позиционирование)
* Методология БЭМ (Nested)

## Структура проекта
* `index.html` — основная разметка страницы;
* `styles/` — стили проекта (`style.css`, `global.css`);
* `fonts/` — шрифты Raleway;
* `images/` — графические материалы (изображения лотов, логотипы, иконки соцсетей).

## Как запустить
Просто откройте файл `index.html` в любом современном браузере.
